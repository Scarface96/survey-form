# Survey Form

A responsive survey form for collecting user feedback and information using HTML and CSS.

## 📋 Overview

A professional survey form template built with HTML and CSS designed to gather user feedback and information in an organized manner.

## 📝 Features

- **Responsive Design** – Mobile and desktop optimized
- **Form Validation** – Required field checking
- **Multiple Input Types** – Text, email, number, radio, checkbox, dropdown
- **Clean Layout** – Professional appearance
- **Instructions** – Clear guidance for users
- **Submit Button** – Easy form submission
- **Customizable** – Easy to modify for different surveys

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Styling and layout
- **Optional JavaScript** – Form validation and submission
- **No Dependencies** – Pure vanilla code

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Scarface96/survey-form.git
cd survey-form

# Open in browser
open index.html  # macOS
# or
start index.html  # Windows
```

Or run a local server:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

Then visit `http://localhost:8000`

## 📖 Form Fields

- **Name** – Text input
- **Email** – Email input with validation
- **Age** – Number input
- **Category Selection** – Dropdown menu
- **Radio Buttons** – Single choice selection
- **Checkboxes** – Multiple selections
- **Feedback Text** – Textarea for comments
- **Terms Agreement** – Checkbox for consent

## 🎨 Customization

Edit `index.html` and `style.css` to:
- Change form fields
- Update colors and styling
- Modify layout
- Add new sections
- Customize labels and placeholders

## 📤 Form Submission

The form can be connected to:
- Email service (formspree.io, etc.)
- Backend API endpoint
- Database
- Form submission service
